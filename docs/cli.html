CLI reference

One binary, no cgo, no runtime dependencies. Point it at a file, a folder, or a URL and it writes GFM Markdown to stdout.

Synopsis

anymd [flags] [file|url ...]
anymd config <path|show|init> [--llm-config FILE]
anymd cache  <path|stats|clean> [--cache-dir DIR]

With no arguments — or the conventional - — anymd reads stdin. With a single input and neither -o nor -d it writes to stdout.

The stream contract

stdout is Markdown. stderr is diagnostics. Progress lines, warnings and errors never touch stdout, on any code path, so the output of a run is exactly the document and nothing else. That separation is the whole reason anymd composes in a pipeline.

# stdout carries only the document; the progress line goes to the terminal
anymd contract.pdf | grep -n 'Section 4'

# keep the Markdown, discard the chatter
anymd report.docx 2>/dev/null > report.md

# keep the chatter, discard the Markdown (a validity check)
anymd -r inbox/ -d /dev/null 2>errors.log

A short write to stdout is treated as a failure, not a success. anymd big.pdf | head exits non-zero rather than reporting that it converted a document it in fact truncated.

Use -q to silence the per-file progress lines when stderr is being captured and you only want real errors in it.

Exit codes

CodeMeaning
0Every input converted.
1One or more inputs failed — an unreadable file, a scanned PDF with no text layer, an unsupported type, an HTTP error.
2Usage error: an unknown flag, -o FILE with several inputs, -o together with -d, an --llm-* flag without --llm, --cache-dir without --cache.

The split matters in CI: 1 means the document was bad, 2 means the invocation was bad, and those want different responses.

anymd -r ./corpus -d ./out
case $? in
  0) echo "all converted" ;;
  1) echo "some documents failed; see the log" ; exit 1 ;;
  2) echo "bad invocation — fix the script" ; exit 2 ;;
esac

Flags

FlagArgumentDefaultWhat it does
-o, --outputFILE | DIR— Write to FILE. If the path already exists as a directory, batch into it instead.
-d, --outdirDIR— Batch output directory, created if missing. Mutually exclusive with -o.
--ext.md.md Output extension in batch mode. A leading dot is added if you omit it.
-t, --typeEXT— Force an extension hint, e.g. -t docx. Mainly for stdin, which has no filename.
-r, --recursive—off Walk directories given as inputs. Without it, a directory argument is an error.
--charsetNAMEdetected Override the detected text encoding.
--max-depthN8 Bound container recursion — a zip inside a zip inside a zip.
--keep-data-uris—off Keep base64 images inline as data: URIs rather than dropping them.
--title—off Prepend # Title when the converter found one and the body does not already open with an h1.
-q, --quiet—off Suppress the per-file progress lines on stderr. Errors still print.
--fail-fast—off Stop at the first error. The default is to continue and report at the end.
--insecure—off Skip TLS verification when fetching a URL. See Network access.
--list—— Print the registered converters in dispatch order, then exit 0.
--version—— Print version, commit and Go version, then exit 0.

Cache flags

Off by default — anymd writes nothing to your disk unasked. Full detail on the cache page.

FlagArgumentDefaultWhat it does
--cache—off Reuse a previous conversion of identical bytes.
--no-cache—off Force a fresh conversion. Wins over --cache, with a note on stderr.
--cache-dirDIRos.UserCacheDir()/anymd Cache location. Requires --cache; on its own it is a usage error, not a silent no-op.

LLM flags

All off by default. Without --llm, anymd makes no network calls during conversion at all. Each of these is a usage error without --llm, so a typo cannot silently do nothing. See the LLM page.

FlagArgumentDefaultWhat it does
--llm—off Enable LLM image captioning — one model call per image.
--llm-configFILE~/.config/anymd/anymdconfig.json Config file location.
--llm-modelNAMEfrom config Override the vision model.
--llm-base-urlURLprovider default Override the endpoint. A local Ollama or vLLM works.
--llm-timeoutD60s Bound one model call, e.g. 30s. Must be positive.
--llm-transcribe—off Also transcribe audio — one call per file, and it costs money.
--llm-transcribe-modelMwhisper-1 Speech model. A different endpoint from --llm-model, hence its own flag.

Precedence is explicit flag > config file > environment > default. The API key is read from the environment (OPENROUTER_API_KEY, OPENAI_API_KEY or ANTHROPIC_API_KEY), or from the config file via ${VAR} interpolation. anymd never prints a key, not even masked.

Input modes

stdin

No arguments, or a single -. There is no filename to sniff, so give a hint with -t when the bytes are ambiguous.

cat page.html | anymd -t html
curl -s https://example.com/a.docx | anymd -t docx > a.md

A single file

Written to stdout unless -o or -d says otherwise.

anymd report.docx            # to stdout
anymd report.docx -o out.md  # to a file

-o pointing at an existing directory

If the -o path exists and is a directory, anymd batches into it instead of trying to create a file with that name. -o FILE with more than one input is a usage error — use -d.

-d/--outdir and --ext

Batch mode. The output name is the input's basename with its extension replaced by --ext. Two inputs that share a basename do not clobber each other: the second becomes report-1.md, the third report-2.md.

-r recursive

Directory arguments are walked. Symlinks are skipped, and the walk result is sorted, so the input list is the same on every run and on every machine.

URLs

An http:// or https:// argument is fetched rather than opened. Type hints come from the response Content-Type and from the final, post-redirect URL — the URL's own extension wins when it has one. The output basename is derived from the URL path, falling back to the host, then to download.

Network access

A URL argument is the only network access the CLI makes, unless you pass --llm. Converters are offline by construction: they see a plain byte stream and have no client to reach out with. A malicious document cannot make anymd phone home.

URL fetches use a 30-second timeout and identify themselves with a real User-Agent. A non-2xx response is an error, not an empty document.

--insecure disables TLS certificate verification for URL fetches. That means no certificate chain check and no hostname check, so any machine on the path can present its own certificate and read or rewrite the document you are converting. It exists for self-signed internal hosts. Do not point it at the public internet, and do not put it in a script that later gets used against one.

The config subcommand

anymd config path   # print the config file path
anymd config show   # print the resolved config, every secret redacted
anymd config init   # write a starter config (mode 0600); never overwrites

--llm-config FILE is accepted on either side of the verb and overrides the default path.

What config show guarantees

show never prints a secret — not in full, not truncated, not masked. A masked key still leaks its length and its prefix, and it teaches people that showing part of a key is acceptable. So it prints one of three descriptions instead:

SituationWhat you see
Field empty, an env var is set<unset in config; will use $OPENROUTER_API_KEY from the environment>
Field is ${VAR}<set from ${VAR}>, or <references ${VAR}, which is NOT set>
Field holds a literal<set literally in the file — move it to ${VAR} and keep it out of the file>

The guarantee is structural, not a filter: show parses the raw file rather than the resolved config, so the key's value is never loaded into a variable that a later careless edit could print.

The same treatment covers everything else that can hide a credential. A proxy URL is parsed and any embedded userinfo becomes <redacted>, so http://user:pw@proxy:3128 prints as http://%3Credacted%3E@proxy:3128. Every custom header value goes through the identical redaction as api_key, because a header is just as likely to be a token.

The cache subcommand

anymd cache path    # print the cache directory (never creates it)
anymd cache stats   # entry count, total size, budget, version key
anymd cache clean   # delete every cached entry

--cache-dir DIR is accepted on either side of the verb. Caching is off unless you pass --cache to a conversion. Because the key covers the anymd version, an upgrade invalidates the cache on its own — clean is for reclaiming disk space, not for correctness. See the cache page.

Batch determinism

Inputs are converted on a worker pool sized to runtime.NumCPU() (capped at the number of inputs), but results are emitted in input order, never completion order. A run's stdout and its file-writing sequence are therefore identical every time, whatever the machine or the scheduling.

That is what makes a batch run diffable. You can convert a corpus twice and compare, or commit the output and see only real changes in the next diff — which is also how anymd's own regression suite works.

A multi-input run ends with a stderr summary: converted 12, failed 1. With --fail-fast, the first failure cancels the remaining jobs and reporting stops there.

Worked examples

Pipe a file

cat notes.docx | anymd -t docx | less

Batch a folder into a directory

anymd -r ./contracts -d ./markdown --ext .md
# stderr: converted 218, failed 2
# ./markdown/*.md, written in the order ./contracts was walked

Convert a URL

anymd https://example.com/report.pdf > report.md
anymd https://example.com/a.pdf https://example.com/b.pdf -d ./out

Force a type hint on stdin

# the bytes are a spreadsheet, but a pipe has no filename
gunzip -c sales.xlsx.gz | anymd -t xlsx

Feed a RAG pipeline

#!/usr/bin/env bash
set -uo pipefail

# One document per file, deterministic order, titles preserved for chunk headers.
anymd -r ./corpus -d ./chunks --ext .md --title -q 2> ingest.err
status=$?

# 1 means some documents were bad; ingest the rest and review the log.
# 2 means the command line is wrong; ingesting anything would be a mistake.
[ "$status" -eq 2 ] && { cat ingest.err; exit 2; }

for f in ./chunks/*.md; do embed "$f"; done
[ "$status" -eq 1 ] && echo "skipped $(grep -c '^anymd:' ingest.err) documents" >&2
exit 0

Add --cache when the same corpus is re-ingested — see when the cache pays. Add --llm only if you want image captions and accept the network calls and the cost.

Registered converters

anymd --list prints them in dispatch order — the order they are offered the stream, first match wins:

audio  csv  docx  epub  image  ipynb  msg  pdf  pptx
rss  xls  xlsx  json  html  zip  plaintext

plaintext is last because it is the fallback that accepts anything. What each one extracts is on the formats page.
