anymd

Convert any document to Markdown — a pure-Go library and CLI. No cgo. No Python. No native library to ship.

Install

# CLI
go install github.com/muthuishere/anymd/cmd/anymd@latest

# or, without Go
curl -sSfL https://raw.githubusercontent.com/muthuishere/anymd/main/install.sh | sh

# library
go get github.com/muthuishere/anymd

Use it

$ anymd report.docx > report.md
$ anymd *.pdf --outdir ./md
$ cat data.xlsx | anymd -t xlsx
$ anymd https://example.com/post.html
md, err := anymd.ConvertFile("report.docx")
if err != nil {
    log.Fatal(err)
}
fmt.Println(md.Markdown)

Why this one

One static binary

Builds with CGO_ENABLED=0 and cross-compiles anywhere Go does. Nothing to install alongside it.

Library first

The CLI is a thin wrapper. Embed the converter in your own service without shelling out.

Built for hostile input

Fuzzed per format. Bounded allocations, zip-bomb caps, no network at convert time.

Honest failures

A scanned PDF returns ErrNoTextLayer, never a silent empty string.

Formats

FormatExtracted
Wordheadings, lists, tables, links, image alt text, title
PowerPointslide text, tables, charts, image alt text, speaker notes
Excelevery sheet as a heading + table — .xlsx and legacy .xls
PDFtext layer, page by page
HTMLheadings, lists, tables, links, with charset detection
EPUBspine order, chapter by chapter, metadata
Outlook .msgsubject, From/To/Cc/Date, HTML or plain body
ZIPrecursive conversion of every member, depth-bounded
FeedsRSS and Atom, per-entry
Notebooksmarkdown + code cells, text outputs
DataCSV, TSV, JSON, plain text
Imagesdimensions and EXIF (camera, exposure, GPS)

What it deliberately does not do

No OCR. No audio transcription. No LLM captioning. No network access during conversion. Each needs a model or a fetch, and shipping either would cost the single-binary promise that is the reason to choose this library. A scanned PDF returns a named error so you can route it to an OCR service yourself.

Verified against markitdown's own corpus

Checked against the 31 test files in Microsoft markitdown's test suite, not only fixtures we wrote ourselves. 26 of 31 convert. The other five are the scope decisions above — one scanned PDF, three audio files, one random binary that is correctly refused rather than emitted as garbage.
