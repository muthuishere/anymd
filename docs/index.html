anymd

Convert any document to Markdown — a pure-Go library and CLI. No cgo. No Python. No native library to ship.

Install

# CLI
go install github.com/muthuishere/anymd/cmd/anymd@latest

# or, without Go
curl -sSfL https://raw.githubusercontent.com/muthuishere/anymd/main/install.sh | sh

# library
go get github.com/muthuishere/anymd

Use it

$ anymd report.docx > report.md
$ anymd *.pdf --outdir ./md
$ cat data.xlsx | anymd -t xlsx
$ anymd https://example.com/post.html
$ anymd --llm scan.pdf              # opt in: caption images, read a scan
md, err := anymd.ConvertFile("report.docx")
if err != nil {
    log.Fatal(err)
}
fmt.Println(md.Markdown)

Why this one

One static binary

Builds with CGO_ENABLED=0 and cross-compiles anywhere Go does. Nothing to install alongside it.

Library first

The CLI is a thin wrapper. Embed the converter in your own service without shelling out.

Built for hostile input

Fuzzed per format. Bounded allocations, zip-bomb caps, and no network at convert time unless you ask for it.

Honest failures

A scanned PDF returns ErrNoTextLayer, never a silent empty string.

Optional: LLM features

By default there is no OCR, no captioning, no transcription, and no network access at all during conversion. That is the default on purpose — it is what makes it safe to point at a document someone emailed you. One flag opts in:

$ anymd --llm deck.pptx                      # caption every figure
$ anymd --llm scan.pdf                       # read a page with no text layer
$ anymd --llm --llm-transcribe interview.m4a # transcribe audio

Captioning is one model call per distinct image (a logo repeated on every slide is captioned once); transcription is one call per file. Configure it in ~/.config/anymd/anymdconfig.json, where every field supports ${VAR} interpolation so the key stays in your environment:

$ anymd config init   # starter config, mode 0600, never overwrites
$ anymd config show   # resolved config — api_key: <set from ${OPENROUTER_API_KEY}>
$ anymd config path

anymd never prints an API key — not in an error, not in config show, not masked. Precedence is explicit flag > config file > environment > default. Point --llm-base-url at a local Ollama or vLLM and nothing leaves the box at all.

What it still does not do

No pixel-faithful rendering or layout geometry. No writing documents — it is one-directional. And nothing at all over the network unless you passed --llm: a document can never make anymd phone home on its own.

Verified against markitdown's own corpus

Checked against the 31 test files in Microsoft markitdown's test suite, not only fixtures we wrote ourselves. 26 of 31 convert in the default offline build. Of the other five, the scanned PDF and the three audio files convert once --llm is on; the remaining one is a random binary, correctly refused rather than emitted as garbage.
