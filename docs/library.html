The Go library

Point anymd at a document and get GitHub-flavored Markdown back. Pure Go, no cgo, no interpreter, and no network call unless you hand it a model.

Install

go get github.com/muthuishere/anymd

The module is github.com/muthuishere/anymd and requires Go 1.26. There is no cgo anywhere in the dependency graph, so CGO_ENABLED=0 builds work and the module cross-compiles anywhere Go does:

GOOS=windows GOARCH=arm64 CGO_ENABLED=0 go build ./...

For the command-line tool instead, see the CLI page.

Quick start

The three-line case, using the package-level helpers backed by Default():

res, err := anymd.ConvertFile("report.docx")
if err != nil {
	log.Fatal(err)
}
fmt.Println(res.Markdown) // and res.Title, when the format carries one

For bytes you already hold, use ConvertBytes; for an arbitrary reader, use Convert. Each takes a StreamInfo of hints — extension, MIME type, filename, charset, origin URL — every field optional. With no hints at all, dispatch falls back to sniffing the first 512 bytes.

The snippets on this page are lifted from example_test.go, which is compiled and executed by go test, so they cannot drift from the API.

A reader, with one hint

doc := strings.NewReader(`
	<html><head><title>Quarterly Notes</title></head><body>
	<h1>Quarterly Notes</h1>
	<p>Revenue is <b>up</b>.</p>
	<ul><li>EMEA</li><li>APAC</li></ul>
	</body></html>`)

res, err := anymd.Convert(doc, anymd.StreamInfo{Extension: ".html"})
if err != nil {
	log.Fatal(err)
}
fmt.Println("title:", res.Title)
fmt.Println(res.Markdown)

// title: Quarterly Notes
// # Quarterly Notes
//
// Revenue is **up**.
//
// - EMEA
// - APAC

Bytes in memory

csv := []byte("region,seats,renewed\nEMEA,120,yes\nAPAC,64,no\n")

res, err := anymd.ConvertBytes(csv, anymd.StreamInfo{Extension: ".csv"})
if err != nil {
	log.Fatal(err)
}
fmt.Print(res.Markdown)

// | region | seats | renewed |
// | --- | --- | --- |
// | EMEA | 120 | yes |

The core types

TypeWhat it is
EngineA converter registry. New() returns one with every built-in registered; the zero Engine is empty.
ConverterTwo methods, Accepts and Convert. One family of formats.
StreamInfoHints about a stream: MimeType, Extension, Charset, FileName, URL. Every field optional.
OptionsPer-conversion knobs. A nil *Options and the zero value both give the defaults.
ResultMarkdown string and Title string. Result.String() returns the body, so it prints directly.

Package-level helpers

Each of these uses Default(), the shared engine built on first use:

func Convert(r io.Reader, info StreamInfo) (Result, error)
func ConvertBytes(b []byte, info StreamInfo) (Result, error)
func ConvertFile(path string) (Result, error)
func Default() *Engine

Default is a function rather than a variable on purpose. Go initializes package-level variables before it runs init(), and every converter registers itself from an init(); a var Default = New() would capture an empty registry and make every helper return ErrUnsupported.

Engine methods

func New() *Engine
func (e *Engine) Register(c Converter)
func (e *Engine) Converters() []string
func (e *Engine) ConvertStream(r io.Reader, info StreamInfo, opts *Options) (Result, error)
func (e *Engine) ConvertBytes(b []byte, info StreamInfo, opts *Options) (Result, error)
func (e *Engine) ConvertFile(path string, opts *Options) (Result, error)

ConvertStream buffers a plain io.Reader into memory first, because dispatch has to rewind. Hand it an io.ReadSeeker (an *os.File, a *bytes.Reader) to avoid that copy.

StreamInfo helpers

info := anymd.StreamInfoForFile("/data/q3.PDF")
info.Ext()                       // ".pdf" — lowercased, leading dot guaranteed
info.NormalizedMime()            // mime type, lowercased, ";" parameters stripped
info.HasExt(".pdf", ".ps")       // extension hint matches one of these
info.HasMimePrefix("image/")     // normalized mime starts with a prefix
info.CopyAndUpdate(other)        // copy with every non-empty field of other applied

Options

FieldDefaultEffect
MaxDepth int0 → 8Bounds container recursion. Negative disables recursion entirely.
KeepDataURIs boolfalseKeeps base64 image payloads inline as data: URIs instead of dropping them.
Charset stringdetectedOverrides the detected encoding for text-ish formats.
Cache CachenilServes and stores conversions content-addressed. See Cache.
Describer DescribernilCaptions images and reads pages with no text layer. See LLM.
Transcriber TranscribernilConverts audio to text. Without one, audio formats are not accepted at all.

Nil is the interesting default. With Describer and Transcriber both nil — which is what you get from the zero Options — a conversion makes no network calls of any kind. That is the property that makes it safe to point at untrusted input.

The dispatch model

Dispatch is deliberately simple, because predictability is the feature.

  1. Hints first. StreamInfo carries the extension, MIME type and filename you already know.
  2. Then sniffing. If the MIME hint is empty, the engine reads the first 512 bytes and fills it in with http.DetectContentType. Individual converters sniff their own magic bytes inside Accepts.
  3. Priority order. Converters are tried in ascending priority, ties broken by registration order.
  4. First Accepts wins. No scoring, no voting, no second opinion.
ConstantValueFor
PrioritySpecific0An unambiguous magic number or unique extension: docx, pdf, xlsx. The default for a converter that implements no Prioritized.
PriorityGeneric10A broad family that would otherwise shadow a specific format: html, zip-as-container.
PriorityFallback100The single last-resort text converter. Exactly one converter should sit here.

The two methods have very different budgets. Accepts runs against every registered converter on every conversion, so it must stay cheap: hints and magic bytes, never a full parse. It may read from r freely and need not rewind — the engine seeks back to 0 before every Accepts and before Convert.

Accepting and then failing is a hard error

If a converter accepts a stream and its Convert returns an error, the engine returns that error. It does not fall through to the next candidate.

That is a design choice, not an oversight. Falling through means a corrupt .docx quietly comes back as the plaintext converter's rendering of compressed XML — which looks like output, diffs like output, and is garbage. An error the caller can see beats plausible nonsense they cannot. The failure mode this whole project exists to avoid is a pipeline that indexes rubbish and reports success.

_, err := e.ConvertBytes([]byte("BEGIN:VCARD\nEND:VCARD\n"),
	anymd.StreamInfo{Extension: ".vcf"}, nil)
fmt.Println("err:", err)
// err: anymd: vcard: vcard has no FN (formatted name) property

The error is wrapped with the converter's name, so you always know which one claimed the stream.

Inspecting the registry

Engine.Converters() returns the live registry in dispatch order, which is always the authoritative answer for the build you have:

names := anymd.New().Converters()

fmt.Println("last:", names[len(names)-1])
fmt.Println("has csv:", slices.Contains(names, "csv"))
fmt.Println("has pdf:", slices.Contains(names, "pdf"))
// last: plaintext
// has csv: true
// has pdf: true

The invariant worth relying on is the last line: the text catch-all sits alone at PriorityFallback, so it is always last. See Formats for what each converter extracts.

The typed unsupported error

Use the sentinel for a quick branch and the typed error for the detail worth logging:

// Binary bytes with a NUL, so even the text fallback declines.
blob := []byte{0x00, 0x01, 0x02, 0x03, 0xff, 0xfe}

_, err := anymd.ConvertBytes(blob, anymd.StreamInfo{Extension: ".widget"})

fmt.Println("unsupported:", errors.Is(err, anymd.ErrUnsupported))

var ue *anymd.UnsupportedError
if errors.As(err, &ue) {
	fmt.Println("ext:", ue.Ext)
	fmt.Println("mime:", ue.Mime)
	fmt.Println("declined some:", len(ue.Declined) > 0)
}
// unsupported: true
// ext: .widget
// mime: application/octet-stream
// declined some: true

Declined names every converter that looked at the stream and passed. It is deliberately not part of Error(): a container converter such as zip embeds a member's error text into the Markdown it produces, and a reader should not find the converter registry printed inside their document.

Why a scanned PDF is an error

_, err := anymd.ConvertBytes(scan, anymd.StreamInfo{Extension: ".pdf"})

fmt.Println("no text layer:", errors.Is(err, anymd.ErrNoTextLayer))
// no text layer: true

A pure scan — every page a single raster image — could be reported as a successful conversion producing "". It is not, because "" is exactly what a genuinely blank document produces, and the caller would have no way to tell them apart.

The distinction is operationally load-bearing. "There is nothing to extract" ends the job. "The text is locked inside images" is a signal to route the file to an OCR step, or to supply a Describer. An error that collapses those two cases pushes the ambiguity onto every caller forever. Same reasoning for ErrEncryptedPDF: an encrypted file must never be mistaken for an empty one.

Writing your own converter

A converter is two required methods, plus two optional ones. Here is a real one for a made-up format, written the way a consumer would write it:

type vcardConverter struct{}

// Optional. Without it the engine falls back to the Go type name.
func (vcardConverter) Name() string { return "vcard" }

// Optional. Without it the converter is registered at PrioritySpecific.
func (vcardConverter) Priority() int { return anymd.PrioritySpecific }

func (vcardConverter) Accepts(r io.ReadSeeker, info anymd.StreamInfo, opts *anymd.Options) bool {
	if info.HasExt(".vcf") {
		return true
	}
	var head [11]byte
	n, _ := io.ReadFull(r, head[:])
	return string(head[:n]) == "BEGIN:VCARD"
}

func (vcardConverter) Convert(r io.ReadSeeker, info anymd.StreamInfo, opts *anymd.Options) (anymd.Result, error) {
	b, err := io.ReadAll(r)
	if err != nil {
		return anymd.Result{}, err
	}
	name, rows := parseVCard(b) // your parsing
	if name == "" {
		// Accepting and then failing is a hard error: the engine does not
		// fall through to a catch-all that would emit the raw file.
		return anymd.Result{}, errors.New("vcard has no FN (formatted name) property")
	}
	md := "# " + name + "\n"
	if len(rows) > 0 {
		md += "\n" + strings.Join(rows, "\n") + "\n"
	}
	return anymd.Result{Markdown: md, Title: name}, nil
}

Register it on your own engine:

e := anymd.New()          // every built-in
e.Register(vcardConverter{}) // yours, ahead of the fallback

res, err := e.ConvertBytes(card, anymd.StreamInfo{Extension: ".vcf"}, nil)

Priority is how you win. A .vcf file decodes as UTF-8 text, so at PriorityFallback or later the plaintext catch-all would claim it first and emit the raw file. PrioritySpecific is the right home for a converter keyed to a unique extension and magic string. To override a built-in, register at a lower priority than it.

Register mutates the Engine. Do all registration before the first conversion and before sharing the engine across goroutines.

internal/mdutil — the table, heading and joining helpers the built-in converters share — is an internal package, so an out-of-tree converter cannot import it. Build your Markdown with the standard library, or vendor what you need. This is a consequence of Go's internal rule, not a policy: keeping those helpers unexported means their signatures stay free to change without breaking anyone.

Containers and recursion

Container converters — zip, epub, msg — recurse through Options.Recurse, never by constructing a fresh Engine. Recurse carries the same engine and options down and increments the depth counter, which is what makes MaxDepth real rather than advisory.

func (o *Options) Recurse(r io.ReadSeeker, info StreamInfo) (Result, error)
func (o *Options) Depth() int

Past the limit, Recurse returns ErrMaxDepth. A container reports that inline against the offending member and keeps walking its siblings — losing a whole archive because one member nested too far would be the wrong trade:

// A zip containing a zip containing note.txt.
shallow, _ := e.ConvertBytes(outer, anymd.StreamInfo{Extension: ".zip"},
	&anymd.Options{MaxDepth: 1})
fmt.Print(shallow.Markdown)
// ## inner.zip
//
// ## note.txt
//
// *[could not convert: anymd: max recursion depth exceeded]*

deep, _ := e.ConvertBytes(outer, anymd.StreamInfo{Extension: ".zip"},
	&anymd.Options{MaxDepth: 2})
fmt.Print(deep.Markdown)
// ## inner.zip
//
// ## note.txt
//
// hello from the inside

Concurrency and safety

Once built, an Engine is safe for concurrent use. Register is the mutation, so finish registering before you start converting.

Every converter is a parser aimed at bytes someone else chose, so the posture is explicit:

  • Never panics. Malformed input is an error. Lengths, indices and offsets read out of a document are treated as attacker-controlled, and a dependency that reports corruption by panicking is wrapped in a recover. Finding a way to panic a converter is a bug worth reporting.
  • Allocations are bounded. Per-format input caps, cell and glyph caps, and zip-bomb limits (per-entry, archive-wide, and entry-count). A declared uncompressed size is never trusted to size a buffer.
  • Recursion is bounded centrally by Options.MaxDepth via Options.Recurse.
  • No network, no subprocess, no shell at convert time. A document cannot make anymd phone home. The exceptions are both things you asked for: the CLI's explicit URL argument, resolved before any converter sees a byte, and a Describer or Transcriber you supplied yourself.
  • No cgo, so there is no memory-unsafe parser in the dependency graph.
  • Archive member names that try to escape the root — absolute paths, drive letters, .. components — are refused rather than repeated into output.

A Describer failure is deliberately not an error for the document: a model outage or a rate limit costs you the caption, not the conversion. A Transcriber failure is an error, because the transcript is the audio file's entire content.
